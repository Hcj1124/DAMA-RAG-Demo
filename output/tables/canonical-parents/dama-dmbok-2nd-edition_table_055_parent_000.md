| Example Scenario | How it might manifest |
| --- | --- |
| Addressing Data Quality | 'We've bought a Data Quality tool. That's fixed that now.' • No one in the organization is reviewing or acting on data quality reports |
| Confusing capability delivery with implementation and operation | 'We've implemented the reporting stack for Regulation X. We are now compliant with the legislation.' • Regulatory requirement changes • Nobody is reviewing or acting on issues identified in reporting |
| Migration of data | 'All the data in System X is now in System Y.' • Record counts match, but the data in System Y is incomplete, or truncated due to failures in the migration process. Manual interventions needed |
